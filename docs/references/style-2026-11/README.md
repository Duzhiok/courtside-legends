## 三、和现有计划的关系

- **大部分已覆盖**：M1 首页、M2 一键开打/绝杀、M3 2D、M4 My Legacy 都有。我没有发现需要改动路线图的冲突。
- **真正的新增只有两条**，已记入 BACKLOG（B8、B9），不插队。
- **视觉统一建议**：深海军蓝底 + 金色强调 + 大图居中，把 09/13/21/36/39 当作 2.0 的统一风格基线。现在的游戏主体是深绿色，M1 重构时需要决定是否换色。这是个设计决策，等你定。
