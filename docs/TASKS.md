# 任务清单（持续更新 —— 每次有进展都在这里打卡，不用去 WORKNOTE 里翻）

来源：用户一次性甩来的 16 条反馈（#1–#16）+ 后续"把天马行空的玩法都塞进自定义"的追加要求。

规则：
- 每一个 **feature 方向**算一个独立 task，有自己的 ID、状态、一句话说明。
- bug 类反馈（有明确根因、已经修复验证过的）不在这张表里长期占位，完结后归档到下方「已完成」区，细节永远在 `docs/WORKNOTE.md` 对应的 R 编号里，不重复抄一遍。
- 状态只有四种：`📋 排队中` / `🔜 进行中` / `✅ 完成` / `🏗️ 待排期`（规模太大，需要先出设计再动工）。
- 每次任务有实质进展（开始/完成/卡住），就更新这张表 + 在文件底部「进展日志」补一行，不允许只在对话里说说就算数。
