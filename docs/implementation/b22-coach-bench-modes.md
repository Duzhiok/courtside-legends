## 1. 先核对：「可收起」早就有了

教练席已经有抽屉（`coachDrawer.js`，`.coach-open`）：活球时只留一条动作栏，死球窗口（暂停/节间/伤病）自动展开，也可手动开。所以 B22 真正缺的只有**抽屉里面**的简单/高级分层。没有重做抽屉。

## 3. 简单模式保留 / 隐藏什么

| 保留（`.adv-only` 之外） | 高级才有（`.adv-only`，**只藏不删**） |
|---|---|
| 叫暂停、大喊、继续比赛、速度、暂停模拟、保存并离开、势头条 | 回合重点（两处下拉）、死球里的节奏下拉（与"战术接管"里的提速/降速是同一个 API，简单模式留后者） |
| 战术接管里的**节奏三档**（降速/正常/提速） | 技能包、已购技能、`live-packs` |
| **战术下拉：3 个**（见 §4）+ 布置 | 沟通、个人攻防指令、临场执教方针滑块、场上站位、对位/防守布置 |
| 快速模拟整场、保存进度、保存并离开 | 士气/化学/适配度仪表、三个托管开关、暂停策略三档、托管提示 |
| 换人（板凳，面板之外） | 战术接管的"隐藏"按钮、"当前：…"状态行、提到"回合重点"的说明段 |

所有控件**保留原 id 和原有 GameSim 接线**；隐藏只是 CSS（`.coach-panel[data-coach-mode="simple"] .adv-only { display:none }`），没有删除任何功能。

## 4. "3 个常用战术"怎么选（`simpleTactics`，纯函数）

教练能用的战术取决于教练和阵容，不能写死三个 id。规则：

1. **基线 = 这位教练自己的体系**（`coachTactics(coach)[0]`；没有就 `balanced`）。
2. **最快**（`pace` 最大，追分用）。
3. **最稳**（`defense` 最大，保领先用）。

例（全部战术池）：均衡进攻 / 转换突击 / 铁血半场。三项**只取决于战术池，不随当前选择变化**（选了其中一个，另外两个不会跟着换）；当前下拉值若不在三项内会被**追加**，保证下拉不会"说谎"。简单模式的下拉是**平铺重建**的，不是给选项加 `hidden`（iOS Safari 对 `<option hidden>` 无效）。

## 5. 默认值与持久化

- 设备偏好 `localStorage["cls_coach_mode_v1"]`，**不进存档/账号**（和 2D/3D 渲染器偏好同类）。
- **默认简单。** 老玩家第一次打开教练席会看到简化版，右上角一个 44px 的"高级"开关；点一次就记住。我没做"老玩家默认高级"的判断：没有可靠的"老玩家"标志，而且猜错会比多点一次更糟。

### 浏览器 QA 抓到的一个真问题（已修）

第一版脚本的"可见"检查只看 `display`/尺寸，报告全 PASS；截图却显示桌面上战术下拉和保存按钮被教练席**自己的滚动框**挡住了（该框在固定行高里：1440×900 只有 288px，简单模式内容 590px、高级 2316px）。简单模式如果还要滚两屏，就失去意义。修法（只改 CSS）：简单模式打开时 ① 球场让到 `max(200px, 28vh)`；② 面板内容分两栏（节奏 | 战术 + 保存行）；③ 隐藏冗余的状态行/隐藏按钮/过时说明（内容 590 → ~390px）；④ 高度 ≤ 940 的桌面屏这一行多给 72px。实测 1280×800 / 1366×768 / 1440×900 / 1536×864 / 1600×900 / 1920×1080 / 2560×1440 **都放得下**（`scrollHeight ≤ clientHeight`）。脚本的 `seen()` 随后改成感知裁切，并加了"面板无需滚动"断言。**高级模式没动**，仍是原来的内部滚动。
