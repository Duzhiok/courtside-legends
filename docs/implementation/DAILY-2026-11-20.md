## 三、今天新发现(未修,等设计取舍)

**Story clutch 不是配线 bug,是漏斗窄**(2 个真有上场的赛季,164 场):

| 层 | 场数 |
|---|---|
| 接管被接受 | 42 |
| 真的出手 | 13(**29 场"没能出手"是最大的一次流失**) |
| 终场分差 ≤3 | 6 |
| 有直接对位对手 | 6 |
| 第 2 次以上交手 | 3 |
| 形成 clutch 宿敌 | **0** |

0 的原因:`MAX_ACTIVE_RIVALS=3` 在第 34–53 场前就被 taunt/auto 占满(种子 1:第 22/29/34 场满额,之后的 clutch 时刻全被挡);种子 4 里同一场 taunt 优先于 clutch。clutch 判断用的是**终场**分差,不是接管时的分差。

**新秀试用期**(4 个固定种子,82 场,每周都训练):
- 浏览器 smoke(桌面+手机)ALL PASS:教练阶梯、没上场不扣信任、训练日 XP、虚构新秀有命中。
- 但种子 2(OVR 68 虚构新秀,深阵容)全季只有 178 分钟、`min12=0`,信任停在 23–29,最终角色 garbage:**几乎没有向上的路**。历史低评分球员(OVR 41/42)同样,这个属于真实性,不算问题。
