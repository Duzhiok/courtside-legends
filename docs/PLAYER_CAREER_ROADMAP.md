# 球员生涯（「我的球员」）路线图

> 状态：**设计稿，未开工**。和 `CAREER_LIFE_ROADMAP.md`（教练生涯）平行的一条线。
> 规矩同教练路线图：每一步一个提交、单测 + 浏览器 QA、不编造真实球员的数据、中英双语。

## 0. 用户原话归纳（需求来源，不改写）

1. 创建账号后可选「个人生涯」：先捏一个**成年后的脸**，再选身高、天赋加点（自由属性点共 **100**），参考 NBA 2K 个人生涯，最后形成成年形象。
2. 从小时候开始：选出生地（海外，或美国某个州），选理想大学，一步步通过选择，**成功或不成功**地升入理想大学。
3. 打大学比赛、三月锦标赛（「疯狂三月」）、然后选秀；故事性要拉满。
4. 公寓（E3 的住房模型）按自己的工资选；场外训练可以加属性。

## 1. 判断：有搞头，而且是这个项目最有特色的一条线

- **这就是最开始问的"个人穿越回去打球"**：你的球员可以出生在任何年代，被选进**那一年真实的选秀班**（比如 1996，和科比、艾弗森、纳什同一届），和真实名册里的球员同场。2K 做不到任意年代，这是本项目独有的资产（1951–2025 全部真实赛季卡）。
- **大部分引擎已经有了**，新东西主要是"外壳 + 内容"：

| 需要的能力 | 现成的模块 | 要补的 |
|---|---|---|
| 一场比赛里你的数据 | `GameSim`（`js/engine/sim.js`），你的球员就是一张普通卡 | 只看"你"的视角：分钟由教练决定 |
| 赛后结算、成长、领悟、热度 | C1 `gameRewards`、C2 `playerGrowth`、C3 `seasonEpiphany`、C4 `buzz` | 改成以"你"为中心的那一行 |
| 选秀 | `leagueDraft.js`（真实选秀班 + 生成新秀） | 把你插进某一年的选秀板 |
| 剧情事件 | A2 `eventPool.js`（带条件的事件池） | **内容**：每个阶段的事件 |
| 每周精力 / 场外训练 | A3 `calendar.js`、`coachProfile` 的精力 | 训练 → 属性 XP（接 C2） |
| 住房 / 工资 | E3 `finance.js`（公寓 / 独栋 / 豪宅） | 住房档按工资开放 |
| 头像 | `avatarArt.js`（程序化 SVG） | 可捏的脸：分层部件 |
| 退休 / 传奇总评 | B7 `legacy.js` 的思路 | 球员版评分（名人堂线） |

- **真正的成本是两样**：① 捏脸美术（分层 SVG，可控）；② **剧情文字量**（童年→高中→大学→选秀，首版约 60–80 个事件，中英双语）。代码本身不吓人。

## 2. 设计原则

1. **你的球员是一张普通卡**：用和真实球员同一套属性键（`scoring three mid paint pass defense rebound steal block speed …`），引擎不分"真人卡"和"你"，平衡就不会被特殊分支破坏。
2. **入行前的一切都是虚构的**：高中、大学的队友和对手全部是生成球员；**不给真实球员编高中/大学数据**（同教练路线图原则）。真实球员从 NBA 开始出现。
3. **100 点不能捏出超巨**：身高决定每项的上限（2K 式：高的人篮板/盖帽上限高、控球/速度上限低）；建档时 OVR 在高中新秀水平（约 45–60），巅峰取决于天赋、选择、训练和运气。
4. **选择要有失败**：理想大学可能进不去，选秀可能落选；失败有出路（别的学校、专科、海外、发展联盟），不是 game over。
5. **按年代守规则**：高中直接进 NBA 只在 2005 年及以前开放（加内特、科比、勒布朗那条路）；2006 起要满 19 岁且高中毕业满一年。
6. **存档只存聚合**：不存逐场日志；脸是一组部件 id，不存图片。

## 4. 风险

1. **商标**：「March Madness」「Final Four」是 NCAA 的注册商标；真实大学的校名和校徽也可能是商标。默认：界面叫「全国锦标赛（三月）」，学校先用**虚构校名按档次**命名；以后要不要换真实校名单独决定（本地自玩和上架是两回事）。
2. **平衡**：你的球员不能靠 100 点 + 训练变成 99 全能；所有成长走同一个上限函数，单测覆盖。
3. **内容量**：剧情是主要成本，先保证每个阶段"少而有后果"，再加量。
4. **和教练线的关系**：两条线共用引擎和存档根，但 `activeMode` 不同；不在一个存档里同时跑两条生涯（首版）。
5. **存档体积**：20 年生涯只存聚合值和事件摘要。
