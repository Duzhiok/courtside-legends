# 场边传奇 · Courtside Legends

按赛季年份抽卡组队，机器模拟比赛输赢；你坐在场边当教练——叫暂停、大喊、布置战术、换人、沟通。

> 空位也会打铁。巨星抱团不无敌。化学反应、阵容适配、战术与性格，共同决定场上表现。

## 快速开始

```bash
cd nba-coach-sim
python3 -m http.server 5173
# 浏览器打开 http://127.0.0.1:5173
```

也可：`npx --yes serve -p 5173`

## 产品需求（完整）

### 核心玩法

1. **模拟 NBA 比赛**：玩家选人组队，胜负由引擎模拟，而非手操投篮。
2. **赛季球员卡**：每位球员标注所属赛季年份；属性由该赛季高低阶数据倾向决定。  
   - 例：凯尔特人时期（2010）奥尼尔吨位仍在，但移动速度与统治力已非巅峰湖人时期。
3. **观看模拟 + 教练指挥**：比赛过程可观看文字回合；玩家可：
   - 叫暂停（恢复疲劳、短时提升攻防）
   - 大喊（抬士气；高自我球员可能反感）
   - 沟通交流（提升化学反应）
   - 布置战术
   - 换人
4. **继续比赛**：暂停后点「继续比赛」或「继续模拟」恢复。

### 隐藏抽卡等级（玩家不可见）

仅影响抽取权重与成长逻辑，**界面永不显示**：

| 隐藏等级 | 说明 |
|---------|------|
| 落选+短期合同+D联盟 | 边缘人选 |
| 饮水机管理员 | 深度板凳 |
| bench player | 轮换 spare |
| starters | 首发级 |
| 球星 | 球队核心 |
| 全明星 | All-Star |
| 名人堂 | Hall of Fame |
| NBA 50 大巨星 | 历史级 |
| 超级巨星 | 当代顶级 |

### 场上表现影响因素

- **化学反应**：自我冲突、持球核过多会拉低效率
- **阵容适配度**：与教练偏好、当前战术契合度
- **战术加成**：三角进攻 / 小球 / 铁血防守等
- **性格**：冷静、火爆、团队型、自我等影响临场波动
- **疲劳**：锡伯杜类教练更耗主力

巨星堆砌若缺少连接者或性格不合，**不一定更强**。

### 真实命中率（反 2K）

- 空位 **不保证** 进球
- 恩比德篮下、库里空位三分都可能打铁
- 回合日志显示预期命中率，便于理解随机性

### 教练系统

- 教练同样带**年份**与属性 Buff（进攻 / 防守 / 士气 / 体力）
- 可自定义倾向的年轻教练卡
- 特殊战术与阵容奇效示例：
  - **禅师（菲尔·杰克逊）**：三角进攻
  - **史蒂夫·科尔**：小球空间
  - **Doc 里弗斯**：鼓舞士气，无复杂体系但凝聚强
  - **锡伯杜**：注重防守，主力消耗大
  - **波波维奇**：纪律与团队篮球
  - **德安东尼**：魔球节奏
  - 等

### 选秀卡 / 潜力

- 新秀卡当前能力一般，**进步空间与成长速度**很高  
  - 例：新秀约基奇、新秀库里

### 游戏模式

| 模式 | 说明 |
|------|------|
| **选秀建队** | 抽球员与教练，对阵 CPU |
| **双人对抗** | 本地两人交替选人，匹配组队开打 |
| **多人淘汰赛** | 2–8 人；每过一轮每人多一次选人机会，打到总决赛 |
| **快速演示** | 系统自动组两队，立刻开打体验指挥 |
