# 场边传奇 · Courtside Legends

> [English version](README_EN.md) · 英文版

按赛季年份抽卡组队，机器模拟比赛输赢；你坐在场边当教练——叫暂停、大喊、布置战术、换人、沟通、装技能、设对位。

> 空位也会打铁。巨星抱团不无敌。化学反应、阵容适配、战术与性格，共同决定场上表现。

**仓库：** [github.com/Duzhiok/courtside-legends](https://github.com/Duzhiok/courtside-legends)

### 最新亮点

- **穿越生涯五年篇章**：回到过去当经理兼教练，五年里经历管理层方向、交易压力、历史偏离与争冠窗口；战绩太差会被解雇，任期结束后谈续约
- **结局分享卡**：五年任期结束生成可截图的总结卡（战绩、冠军、标志性交易、续约结果），还能一键复制战报文字
- **经营决策工具**：球队评估、其他球队主动报价、“保留 / 交易 / 裁掉再签”三方案对比，以及选秀权 OVR 价值折算
- **全新主页**：球馆风格横幅 + 历代传奇球星照片墙，每个模式配代表球星
- **真人头像**：本地插画 → 已署名 Wikimedia 照片 → Basketball-Reference 头像热链 → 程序生成剪影头像，四级回退，几乎不再出现卡通字母头像
- **三路托管**：进攻托管 / 防守托管 / 沿用当前策略（只按疲劳换人、不碰战术）可分别开关，不再是单一的“智能托管”开关
- **球魂养成**：抽到重复卡只攒「球魂」，用球魂把卡升到 ★5 才会送一个技能（抽卡本身不送）；重复卡不会无限叠加变成养成陷阱
- **教练席改版**：桌面端加宽、加高，战术/节奏/换人/对位不用再疯狂下拉
- **位置分配修复**：阵容溢出时按球员身材/技术自动找合适替补位，不会再把高大中锋硬塞去打后卫

## 安装与运行

### 环境要求

- [Git](https://git-scm.com/)（可选，用 zip 解压也可）
- [Python 3](https://www.python.org/)（推荐）或 Node.js（可选）
- 现代浏览器（Chrome / Edge / Safari / Firefox）

> ⚠️ **不要**直接双击用 `file://` 打开 `index.html`，ES Module 与名册加载会失败。必须通过本地 HTTP 服务访问。

### 方式一：从 GitHub 克隆（推荐给朋友）

```bash
git clone https://github.com/Duzhiok/courtside-legends.git
cd courtside-legends
python3 scripts/serve_nocache.py
```

浏览器打开：**http://127.0.0.1:5173/**

`serve_nocache.py` 会关闭缓存头，改代码后刷新即可看到最新效果。

### 方式二：标准静态服务

```bash
cd courtside-legends
python3 -m http.server 5173
# 或
npx --yes serve -p 5173
```

同样打开 http://127.0.0.1:5173/

### 方式三：ZIP 包

1. 在 GitHub 页面点 **Code → Download ZIP**，或把仓库打成 zip 发给对方
2. 解压后进入目录，执行上面任意一种 `python3` / `npx` 命令
3. 浏览器打开 http://127.0.0.1:5173/

### 更新到最新

```bash
cd courtside-legends
git pull
python3 scripts/serve_nocache.py
```

若界面仍像旧版：强制刷新（`Cmd+Shift+R` / `Ctrl+Shift+R`），或主页点「清除名册本地缓存」后重进。

### 可选：重建名册数据

需联网拉取 Basketball-Reference 等源：

```bash
python3 scripts/build_full_roster.py
```

输出：`js/data/roster.json`（游戏启动时异步加载，并写入浏览器本地缓存）。

## 游戏模式

| 模式 | 说明 |
|------|------|
| **自定义对战** | 15 块预算轮抽巅峰卡 → 挑战 32 支历史球队淘汰赛；同入口含双人竞价、传奇八队 |
| **排位赛** | 用本地账号班底 + 教练/战术出战；胜负计入战绩，卡组永久保存 |
| **选秀建队** | 抽球员与教练，打一场完整模拟赛（锁定真实节奏） |
| **常规赛征程** | 32 队联赛，或穿越某历史整年（如 1991：当年全联盟常规赛→季后赛）；自命名拉斯维加斯队；评奖 |
| **金币晋级赛** | 32 随机联队夺冠 → 挑战 15 支历史季后赛 → 再挑战 7 支历史总冠军；进程自动存档 |
| **多人淘汰赛** | 2–8 人本地；每过一轮多一次选人，打到总决赛 |
| **快速演示** | 系统自动组两队，立刻开打看指挥 |
| **联盟经理** | 从主页直接建立长期联盟，沿用赛季建队流程，连续经营 15+ 年的比赛、市场、选秀、发展与历史 |
| **穿越生涯** | 选择历史年份与执教理念、参加球队面试，用有限的未来知识改写五年历史；五年后按表现续约或离开 |

### 自定义子模式

- **预算轮抽**：15 块买 5→1 价巅峰卡并补 0 块板凳，再打历史 32 强淘汰
- **双人竞价**：本地两人竞价买自由球员
- **传奇八队**：随机八支传奇球队，轮抽该队历史球员并指定位置

## 功能一览

### 账号与卡组

- 本地多账号；开局系统发 7 张卡，再自选 5 张组成班底
- **抽卡经济**：按 OVR 分 7 档概率（普通→神话+），10 抽保底全明星、50 抽保底传奇，新手前 5 抽保证一张 85+；年代/球队限定卡池按池内相对排名定档，弱年代也能抽出池内顶级卡
- 每日免费抽 + 任务/排位赚的抽卡券 + 金币加抽（¤200/次，每日 2 次）；教练卡也计入保底次数
- **卡库上限 60 张**（至少保留 12 张）；分解冗余卡换金币与技能碎片，图鉴记录曾拥有过的卡（分解后不丢失）
- **球魂升星**：重复卡只攒心意球员的「球魂」，花球魂把某张卡升到 ★5（上限）；只有升到 ★5 那一下会从普通/稀有/史诗技能里送一个，抽卡自动升星不送
- 「我的球员卡」收藏夹（支持搜索/排序/稀有度/成色/年代筛选）；排位用班底出战

### 名册与球员卡

- **全历史名册**：约 2.3 万+ 张赛季卡 / 4300+ 名球员（1950 起，单季 GP≥5）
- 每张卡绑定**赛季年份**与当季倾向属性（凯尔特人奥尼尔 ≠ 巅峰湖人奥尼尔）
- 头像优先级：本地插画 → 有署名的 Wikimedia 照片 → Basketball-Reference 头像热链（`HOTLINK_HEADSHOTS` 开关，仅建议本地私人使用，公开发布前应关闭或改为本地化下载）→ 程序生成的队色剪影头像兜底
- 队名缩写角标挂在头像左下角外侧，不挡脸
- 年龄曲线：新秀更快更有弹速；老将判断力、力量、传球、手感、领袖与大心脏更强
- 隐藏稀有度（饮水机→超巨等）只影响抽卡权重，**界面永不显示**
- 能力按 NBA 2K 历年标尺从当季数据推算；关键赛季有公开 2K 锚点校正

### 临场指挥（比赛中）

- **活球**：只能「大喊」或「叫暂停」
- **暂停 / 节间 / 中场 / 对方暂停**：可改战术、沟通、换人、站位、方针、节奏、对位、装技能
- 暂停可打断对方连续得分势头
- 换人：场上 / 板凳卡面显示头像与属性，点选确认；伤员限制上场
- 场上可改 PG–C 站位（与占位者互换）
- 个人攻防指令：持球发起人、打法、用量、侵略性、防守重心等
- 比赛节奏：降速保命中 / 正常 / 提速抢回合
- 变速：1x 真实 / 2x / 3x（选秀模式锁定真实节奏）
- 「快速模拟整场」：当前阵容与战术立刻打完

### 赛前布置

- 自选首发五人；角色与目标分钟（按体能分配）
- 自定义执教方针（攻 / 防 / 士气 / 负荷）+ 战术勾选
- **阵容包**：一键五人组，暂停时可切换
- **对位表**：默认同位置互防（PG↔PG…），可手动改；另可设重点盯防 / 包夹 / 下盘顶防
- 指定持球发起人与持球打法

### 金币晋级赛与市场

- 赛制：四人一组、复活赛、两败出局；阶段 32→16→8→4→2→1
- 赢球赚金币；市场买卖球员（最多 12 人，至少 8 人出战）
- 金币不足时买入按钮灰显「差钱」，并标超出预算
- 刷新自由市场 / 教练货架 / 技能包货架（花费金币）
- **球探包**：随机刷出，标出性价比妖人与板凳匪徒
- 聘请主教练（名帅身价更高）；空缺时出战可系统随机补教练组
- 夺冠后可继续挑战历史季后赛 15 队、历史总冠军 7 队
- **自动存档**；主页可继续或丢弃进度
- **伤病平衡**：比赛内与场次间两层伤病判定都设了封顶（单次回合≤ 2%、场次间≤ 16%），普通球员第一轮几乎不会受伤，只有高风险“玻璃人”在深轮次才需要担心

### 技能系统

- **技能来源只有三条**：比赛表现触发的领悟（连续表现达标，概率触发，有次数上限）、技能碎片购买（分解卡换）、球魂将卡升到 ★5 时赠送一次；**奖项（MVP/最佳阵容等）只是荣誉，不再送技能**
- **招牌绝技**：如迷踪步（韦德）、百步穿杨（库里/克莱/利拉德等）、水花接投、后撤步、金鸡独立…随机触发，非必进
- **角色特质**：缠绕盯防、持球克星·3D、火爆脾气等，可挂在非巨星身上
- **组合技**：水花兄弟、空接之城、詹韦连线等——**搭档同场才挂上**，不可购买学习
- **光环**：潜能激发抬队友、防守统领抬全队防守
- **体力类**：铁肺、永动机；**铁人**降伤病风险
- 用技能碎片在技能库购买入库 → 装到球员；**每张卡最多购买 2 个技能**（自带/领悟/球魂赠送的不占这个名额），已满可卸下替换，已购卸下退回技能库
- 装上的已购技能卖掉球员时按约 55% 变现
- 货架刷新提高多样性，铁肺 / 永动机 / 铁人提高曝光
- 技能可在市场、选首发页、比赛暂停时安装

### 模拟与表现

- 回合制模拟；完整 box score（MIN/PTS/REB/OREB/DREB/AST/STL/BLK/TOV/PF/投篮/三分/罚球/+/-）
- 出手逻辑：投篮/三分**倾向**决定会不会投，能力决定准不准
- 空位也可打铁；日志显示预期命中率相关信息
- 化学反应、阵容适配、性格、疲劳、势头、伤病风险（玻璃人 / 铁人）
- 普通球员约 8 分钟连场疲劳到 60；铁肺 / 永动机更耐；节间/中场/暂停恢复不同
- 动态球场：头像站位、攻防推进、比分角标；扣篮高光弹窗

### 教练与战术

- 教练带风格 Buff（进攻 / 防守 / 士气 / 体力）与特殊战术板
- 战术示例：三角进攻、小球、铁血防守、牛角、普林斯顿、五外、挡拆轰炸、换防等
- 阵容条件可解锁额外战术；名帅靠抽卡

### 其他

- **外号徽章**：飞人、黑曼巴、答案、石佛等历史外号只在球队评估的球员资料卡里显示，不混进候选/市场的快速浏览列表
- **价值标签**：「妖人」「高薪低能」等评价不会在未侦察的候选/抽卡里剧透；侦察包生效或已拥有后才显示
- 背景音乐开关（需自备合法音源放到 `assets/audio/basketball-bgm.mp3`，或点「选曲」从本机加载）
- 主页存档条：继续进度 / 丢弃存档
- 清除名册本地缓存（Cache Storage + IndexedDB）

### 穿越生涯：五年篇章（已实现）

- **序章**：选择 1976–2025 历史年份与执教理念，参加三支球队面试，并做一次“未来知识”决策。
- **五年事件链**：第一年管理层方向与核心球员承诺 → 第二年交易压力 → 第三年历史偏离 → 第四年争冠窗口的代价 → 第五年最后一通电话。每个选择会改变管理层信任、媒体压力和时间线偏离度。
- **被解雇**：连续两个赛季胜率低于 40% 会被解雇；单个烂赛季只是压力，不会直接出局。
- **续约谈判**：五年后球队按表现给出不同方案（年限、薪资、权限、特权），也可以拒绝续约带着成果离开。
- **结局**：王朝建筑师 / 历史改写者 / 在压力中离任 / 未完的革命等，结局锁定后不可篡改。
- **结局分享卡**：自动生成 420px 宽的总结卡，包含总战绩、胜率、冠军、改写史实次数、逐季战绩、最多 3 笔标志性交易和合同结果；支持一键复制战报文字。

### 经营决策工具（只推荐，不会自动替你做决定）

- **球队评估**：每名球员的头像、年龄、OVR、能力值、潜力、技能、历史表现和工资，并给出“核心保留 / 轮换保留 / 可交易资产 / 裁员候选 / 观察”建议及理由。
- **主动交易报价**：表现好的球员会引来其他球队报价，报价可能包含球员、潜力新秀和未来选秀权；可以接受或拒绝。
- **方案对比**：并排对比“保留现状 / 接受交易 / 裁掉后签自由球员”对工资、OVR 和阵容人数的影响。只显示真实收到的报价，不编造交易。
- **选秀权价值折算**：按轮次、保护条款和年份估算预计顺位、新秀当前 OVR/潜力和兑现概率，折算成 OVR 价值（例：明年无保护首轮 ≈ +4.5、乐透保护首轮 ≈ +1.9、次轮 ≈ +0.8），并给出“综合价值变化 = 球员能力差 + 选秀权折算”。
- **季后赛数据**：季后赛累计球员数据，但不重复计入常规赛积分榜；技能奖励区分“本次新学”和“领取前已有”。

### 联盟经理与长期联赛（已实现）

- 主页「联盟经理」是完整长期联赛的直接入口，沿用常规赛的年份、队名与阵容搭建流程；独立「常规赛征程」仍是一季模式，不显示长期管理标签。
- 玩家以经理/教练身份选择 1976–2025 历史年份与执教理念，参加三支球队面试，并完成一次有限未来知识决策；目前可玩的故事内容是序章。
- 接受球队后进入共享长期联赛循环，支持确定性的加权乐透与首轮选秀、四年新秀尺度合同，以及选秀→发展→新赛季的分阶段休赛期。
- 1976–2025 使用球员的 NBA **历史首秀年份班**，不是现实中的精确选秀顺位、选秀球队或完整选秀数据；2025 年后使用生成的架空新秀。
- 球员发展可手动设置重点、角色、导师和负荷；手动方案优先于自动建议，并随长期生涯存档。
- 没有未来史实卡的球员会确定性退役：年满 40 岁，或年满 36 岁且 OVR 低于 45；新秀保护只持续首个赛季。
- 「生涯历史」页按年紧凑展示战绩、季后赛结果、奖项、本队首轮新秀、交易与主要事件，不保存完整赛程、box score 或季后赛树。
- 25 年自动回归覆盖生成新秀、阵容上限、选秀/赛季历史长度、紧凑历史投影与根存档往返；交易时间线另有聚焦回归测试。
- 关键选择和长期联赛状态写入可导入/导出的根存档，刷新页面后可继续。

### 可移植的长期生涯存档

- 主页长期生涯栏提供继续、导出和导入。
- 导出文件名为 `courtside-legends-save.json`。
- 导入内容通过验证后，才会替换本地长期生涯槽位。
- 旧版浏览器存档 `cls_savegame_v1` 和 `cls_season_v1` 会迁移，原存档不会被删除。
- 存档默认仍只保存在本机，目前没有云同步。
- 写入前会压缩旧赛季数据（去掉比赛快照等临时内容）；若浏览器存储空间不足，启动时会明确提示并提供“清理缓存并重启”。

| 1950–2011 | TallData `basketball_players` 历史库 |
| 2012–2025 | Basketball-Reference 赛季 Per Game |

同一球员可有多个赛季卡（新秀 / 巅峰 / 晚年独立进池）。属性由该季场均与命中率等推导，并用 2K 锚点校正关键赛季。

## 技术说明

- 纯前端静态页（ES Module），**无需构建、无后端**
- 存档与账号存在浏览器 `localStorage` / IndexedDB（各电脑互不同步）
- 自动化测试：`npm test`（Node 内置 `node:test`，当前 668 个测试，全部通过）
- 静态检查：`npm run lint`（eslint flat config，只启拓 bug 的规则集如 no-undef/no-unused-vars/no-unreachable，不管风格，没有 prettier）

## 原始需求对照（2026-10-23 审计，细节见 docs/WORKNOTE.md R43）

立项时的原始要求逐条对代码核查的结果：

- ✅ 自己决定首发；教练策略可选、执教方针可自定义（四维方针 + 战术勾选）
- ✅ 动态球场：头像站位随回合移动，含攻防阵型（为后续真人动作预留坐标结构）
- ✅ 隐藏属性：引力、领袖气场、杀手本能、化学反应核、隐藏上限等 20+ 项能力值外属性
- ✅ 晋级制主体：赢球赢金币、每轮后市场买卖、名单最多 12 人、输了淘汰
- ✅ 金币晋级赛总决赛系列赛：按用户拍板改**三局两胜**（取代最初的七场四胜设想），每场后可进市场买卖调整阵容（T8，见 docs/WORKNOTE.md R44；常规赛模式的季后赛仍为七场四胜）
- ⚠️ 晋级赛小组段现状是两败出局 + 复活赛，与原始「输了就淘汰」有差异，是否改回一负淘汰待定（T9）
- ✅ 双人模式竞价 bid；双人随机选人；多人淘汰赛每过一轮多一次选人机会，直到总决赛
- ✅ 属性按当赛季数据生成并标注年份（实测：奥尼尔 2000 湖人 OVR 98 / 速度 68 / 力量 99 → 2011 凯尔特人 OVR 74 / 速度 28 / 力量 92）
- ✅ 观赛 + 临场指挥：大喊、暂停、布置战术、换人、沟通
- ✅ 隐藏抽卡九档（落选+短期合同+D联盟 → 超级巨星），只影响权重，界面永不显示
- ✅ 化学反应、阵容适配、战术与性格共同影响表现；巨星抱团不无敌
- ✅ 真实命中率：以当季真实分区命中率起算，空位也可能投丢
- ✅ 教练可抽取、带年份、给全队 buff、招牌战术有特殊加成（禅师三角 / 科尔小球 / 里弗斯鼓舞士气 / 锡伯杜铁血防守且耗主力）
- ✅ 选秀卡带成长潜力（实测：新秀约基奇 OVR 79，成长 95 / 成长速度 90）
