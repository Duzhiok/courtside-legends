# NBA Coach Sim · 教练模拟

一个轻量的浏览器 NBA 比赛模拟游戏：按**赛季年份**选人组队，由引擎模拟输赢，你作为教练临场指挥。

## 快速开始

用本地静态服务器打开（模块脚本不能直接 `file://`）：

```bash
# Python
python3 -m http.server 5173

# 或 Node
npx --yes serve -p 5173
```

浏览器访问：http://localhost:5173

## 玩法

| 模式 | 说明 |
|------|------|
| **选秀建队** | 从卡包选球员与教练，对阵 CPU |
| **双人对抗** | 本地两人交替选人后比赛 |
| **多人淘汰赛** | 2–8 人，每过一轮多一次选人，打到总冠军 |
| **快速演示** | 自动组队，立刻开打 |

### 教练操作

- **暂停**：恢复疲劳、短时提升攻防
- **大喊**：抬士气（高自我球员可能反感）
- **沟通**：小幅提升化学反应
- **布置战术**：三角进攻 / 小球 / 铁血防守等
- **换人**：管理疲劳与适配度

## 设计要点

1. **赛季卡**：同一球员不同年份属性不同。例如凯尔特人时期（2010）奥尼尔吨位仍在，但速度与统治力明显下降。
2. **真实命中倾向**：空位也会打铁；篮下高手也可能空篮不进；射手空位三分按真实区间波动，不是 2K 式「空位必进」。
3. **隐藏抽卡等级**：落选秀 / 饮水机 / 板凳 / 首发 / 球星 / 全明星 / 名人堂 / 50 大 / 超级巨星——只影响抽取权重与成长，**界面不显示**。
4. **化学反应 · 阵容适配 · 性格**：巨星扎堆若缺少连接者或性格冲突，场上效率会打折。
5. **教练 Buff**：科尔小球、禅师三角、锡伯杜铁血防守（主力更累）、Doc 鼓舞士气等，对特定阵容有额外适配。
6. **选秀潜力**：如新秀约基奇 / 新秀库里，当前不强但成长空间大。

## 说明

这是可玩的最小版本（MVP）：本地单机 / 同屏多人，数据为手工整理的赛季倾向值，非实时官方 API。后续可扩展：更多球员、成长养成、在线对战、真实 box score 导入等。
